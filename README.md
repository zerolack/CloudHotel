# CloudHotel 

CloudHotel is a cloud-native Hotel Management System built with PHP, MySQL, and AWS cloud services.

The system provides hotel staff with tools to manage rooms, guests, bookings, and payments through a web-based dashboard.

## Features

 User authentication  
 Hotel dashboard with statistics  
 Room management  
 Guest management  
 Booking management  
 Payment tracking  
 Revenue monitoring  
 Cloud database integration  

## AWS Cloud Architecture

CloudHotel is deployed using AWS cloud infrastructure:

- Amazon VPC - Network isolation
- Amazon EC2 - Application server
- Application Load Balancer - Traffic distribution
- Amazon RDS MySQL - Database service
- Amazon S3 - Storage
- IAM - Access management
- CloudWatch - Monitoring
- AWS CloudFormation - Infrastructure as Code

## Technology Stack

### Backend
- PHP 8.2
- MySQL
- PDO Database Connection

### Frontend
- HTML
- CSS
- Responsive web design

### Cloud
- AWS EC2
- AWS RDS
- AWS ALB
- AWS CloudFormation

## Database Modules

CloudHotel includes:

- Users
- Rooms
- Guests
- Bookings
- Payments

## Deployment

The application runs on an AWS EC2 instance behind an Application Load Balancer with an Amazon RDS MySQL database.
